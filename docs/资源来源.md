## 程序化替代（未使用外部文件）

| 资源 | 替代方案 | 原因 |
| --- | --- | --- |
| 全部 3D 模型（城市、建筑、道具、僵尸、六种植物、豌豆枪、太阳花手部、训练假人） | Three.js 基础几何体（盒体、圆柱、球体）+ 卡通着色（`MeshToonMaterial`），实例化合批 | 主动选择：符合 13.8-A「卡通低多边形」，首屏体积小（NFR2），且无需引入 GLTF 加载链路；M7 换皮时在 `MODEL_ASSETS` 中填入文件即可 |
| 招牌（「超市」「加油站」）与钟面 | Canvas 2D 绘制的纹理 | 需要中文文字，程序化最简单 |
| 豌豆枪「噗」射击音、寒冰射击音、豌豆射手开火音 | Web Audio 合成（滤波噪声 + 下滑正弦） | Kenney 两个包里没有合适的「噗」声 |
| 僵尸低吼、风声环境音、远处低吼 | Web Audio 合成（低频锯齿波 + 颤音 / 滤波噪声） | 未找到体积合适的 CC0 低吼包；合成音可随机音高（FR-AUD-09） |
| 两条背景音乐（平静探索 / 战斗紧张） | Web Audio 实时合成的循环（和弦铺底 + 鼓点） | 避免引入大体积音乐文件；按附近僵尸数交叉淡入淡出（FR-AUD-06） |
| 爆炸、心跳、受伤、死亡、击杀确认、植物生长、藤蔓缠绕 | Web Audio 合成 | 同上 |
| 粒子贴图、弹孔贴花、UI 图标 | 程序化（点精灵颜色、Canvas 绘制、CSS / Emoji 图标） | 体积为零，风格统一 |

## 加载失败时的行为

`src/audio/audioManager.ts` 加载每个登记文件；任何文件加载或解码失败时，在控制台给出警告，并自动改用该条目的合成方案（`synth` 字段），游戏不会中断。
