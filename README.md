# 植物大战僵尸 3D（第一人称版）— 垂直切片

浏览器里的第一人称「射击 + 种植塔防」沙盒：豌豆枪手靠枪、太阳花靠植物设施，在一座四个街区的城市里赚阳光、买东西、种植物、打僵尸。需求来源见 `需求文档.md`（v0.3.1）。

技术栈：TypeScript（严格模式）+ Three.js + Rapier（`@dimforge/rapier3d-compat`）+ Vite，单元测试用 Vitest。

## 运行

需要 Node.js 22.12 或更高版本，浏览器使用最新版 Chrome / Edge（Windows 桌面，键盘 + 鼠标）。

```bash
npm install          # 安装依赖（版本已锁定）
npm run dev          # 开发服务器（支持配置热重载）
npm run build        # 类型检查 + 生产构建，输出到 dist/
npm run preview      # 本地预览 dist/ 中的构建产物
npm test             # 单元测试（等同于 npx vitest run tests/unit）
npm run docs:numbers # 从 JSON 配置重新生成 docs/数值表.md
```

纯本地单机：运行时不发任何网络请求，存档只保存在浏览器 `localStorage`（键名 `pvz3d.save.v1`），设置保存在 `pvz3d.settings.v1`。`npm run preview` 起的是本地静态服务器，没有任何鉴权，只适合在本机试玩。

## 僵尸图鉴

参照《植物大战僵尸》原作，共 7 种僵尸。数值全部在 `src/config/data/zombies.json`，标【待调参】的按原作相对强弱换算。所有僵尸（包括暴怒后的读报僵尸）都比玩家步行（4.5 m/s）慢，玩家永远可以脱战。

| 僵尸 | 本体生命 | 护甲 / 道具 | 移速（游荡 / 追击，m/s） | 特点 | 击杀阳光 | 出没街区 |
| --- | --- | --- | --- | --- | --- | --- |
| 普通僵尸 | 100 | 无 | 0.8 / 1.4 | 基础款 | 10 | 全部 |
| 路障僵尸 | 100 | 头顶路障 200 | 0.8 / 1.4 | 路障打到一半会出现凹痕，打掉后掉在地上，变回普通僵尸 | 15 | 全部 |
| 铁桶僵尸 | 100 | 头顶铁桶 500 | 0.7 / 1.2 | 打铁桶有金属声；爆头打在铁桶上不翻倍 | 25 | 工业区 |
| 撑杆跳僵尸 | 170 | 撑杆 | 1.0 / 3.0 | 追击时遇到 2 m 内的第一株植物或坚果墙会撑杆跳过去（只跳一次，空中不会被藤蔓定住），落地后丢下撑杆，追击速度降到 1.4 | 20 | 商业街、工业区 |
| 读报僵尸 | 100 | 身前报纸 50 | 0.6 / 1.0 | 边走边看报；报纸被打烂后跺脚怒吼 0.6 s，然后以 3.2 m/s 狂奔 | 15 | 商业街、住宅区 |
| 铁门僵尸 | 100 | 铁门 550，只挡正面 ±60° | 0.7 / 1.1 | 从侧面或背后开枪直接打本体；炸弹花同时炸门和本体 | 30 | 住宅区 |
| 橄榄球僵尸 | 100 | 头盔 700，护住头和躯干 | 1.2 / 2.6 | 低头冲锋，攻击伤害 15；只能打腿，或者先把头盔打掉 | 35 | 工业区 |

- 压力每升一级，铁桶、铁门、橄榄球这几种重甲僵尸出现得更频繁；每种类型都有同屏上限（如橄榄球僵尸最多 4 只），全局上限 40 只不变。
- 打掉的路障、铁桶、铁门、头盔和丢下的撑杆会翻滚落地，2 秒后淡出；金属道具落地有响声。
- 击杀飘字会显示这只僵尸给的阳光和类型名，例如「+25 ☀ 铁桶僵尸」（豌豆射手击杀也算，爆头另加 5）。

## 守卫模式

主菜单先选模式：「练习模式」就是原来的城市自由探索，玩法不变；「守卫模式」是新的波次塔防玩法。

- 地图：螺旋同心环城（外 / 中 / 内三圈环道），外墙 4 个入口，每圈之间有 2 个坡道，外圈与中圈之间有一段 4 米高的高架层（2 个楼梯上下），塔楼、水塔、集装箱堆场三个地标用来辨认方向。正中间是核心房。
- 目标：守住核心房。僵尸默认直冲核心；被你打了会反击你；你走到 12 米内、或植物在 8 米内，它会顺路转向；被坚果墙堵死时会拆墙。核心房南面有门，玩家可以进出，僵尸进不去，只能在外面打墙。
- 波次：两波之间有 30 秒倒计时，按 **F** 立即开始下一波（波次之间 F 只用来开波）。每波数量逐波递增，开放的入口逐渐变多。HUD 顶部显示第几波 / 总波数、倒计时或剩余僵尸、核心血条（低于 50% 闪红并有心跳声），小地图显示圈层、已开放入口（红点）、核心和你的朝向。
- 难度：开局选择，主要参数在选难度界面直接显示，全部数值在 `src/config/data/challenge.json`。

| 难度 | 波数 | 核心血量 | 僵尸血量 | 对玩家 / 核心伤害 | 阳光收入 | BOSS 血量 |
| --- | --- | --- | --- | --- | --- | --- |
| 简单 | 5 | 4000 | ×0.8 | ×0.7 | ×1.2 | 3000 |
| 标准 | 8 | 5000 | ×1.0 | ×1.0 | ×1.0 | 4000 |
| 困难 | 12 | 7000 | ×1.25 | ×1.3 | ×0.8 | 6000 |

- BOSS：最后一波会来一只巨人僵尸（约 2 倍体型、扛着电线杆、背上骑着小鬼）。它抡杆前摇 1 秒后砸下，范围内的植物和坚果墙一击摧毁，对核心 200、对玩家 40 伤害；血量降到一半时会把背上的小鬼扔向防线（只扔一次）。小鬼体型小、跑得快。BOSS 出场时 HUD 显示 BOSS 血条。必须消灭最后一波（包括 BOSS 和小鬼）才算「守卫成功」。
- 失败：核心血量归零，或所有玩家倒下（守卫模式不会 3 秒复活）。失败界面可以「重开当前波」：植物、阳光、永久强化、药水和已买物品保留，本波僵尸清空；核心不会被修复，但如果是因为核心被打爆而失败，核心恢复到这一波开始时的血量。
- 守卫模式没有补给箱、阳光包、训练假人和城市埋伏。
- 存档：独立键名 `pvz3d.guard.save.v1`，与练习模式存档互不覆盖。在清场、购买、种植、暂停、退出和关闭页面时保存；读档后从存档所在波的倒计时重新开始。「守卫成功」或「重新开始」会删除守卫存档。

## 调整数值

所有平衡数值都在 `src/config/data/*.json` 中。开发模式下修改并保存 JSON 会立即热重载（校验失败时保留旧配置并在控制台报错）。启动时会校验字段缺失、引用不存在、种子 `availableTo` 与植物 `onlyByCharacter` 是否一致，以及每个角色可同时持有的快捷栏道具种类是否超过 6 种；校验失败会阻止进入游戏并显示错误列表。改完数值后运行 `npm run docs:numbers` 更新 `docs/数值表.md`。
