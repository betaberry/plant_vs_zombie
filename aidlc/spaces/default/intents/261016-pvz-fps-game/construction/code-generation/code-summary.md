## 关键实现决定

- **新增 `game.json`**：移动参数、生命规则、刷怪导演参数、UI 时长、画质档位这些全局数值，在第 11 章的 6 个文件里没有位置。为满足「数值全部在 JSON 中」新增了这个文件，它同样纳入校验和数值表。
- **城市在代码里生成**：按 `map_city_01.json` 生成。共 4 个街区、5 栋可进入建筑（每栋有大厅、2 个后房间、楼梯、2 个二楼房间）、7 个重生点、14 个刷怪点、6 个埋伏点，工业区有 30° 和 10° 两条坡道。已有测试确认真实地图上没有不连通的航点。
- **坚果墙会改变寻路代价**：受影响的边加上拆墙代价，A* 自然会在绕路和拆墙之间选更便宜的那个；只有路径经过这些边的僵尸才重新算路（TR-NAV-04）。
- **用实例化压低 Draw Call**：城市、僵尸、植物、拾取物、弹孔都用实例化渲染；粒子是一个对象池化的点系统；第一人称视图模型单独渲染一遍。
- **3D 模型全部程序化生成**：按 13.8-A 做卡通低多边形，没有下载模型包，换皮时在 `src/assets/registry.ts` 登记文件即可。音效里，命中、界面、脚步这些用 Kenney 的 CC0 素材；枪声「噗」、僵尸低吼、背景音乐、风声、爆炸、心跳用 Web Audio 合成。
- **vitest 锁到 5.0.5**：3.x 版本的依赖带有 `npm audit` 报告的严重漏洞，换版本后为 0。

## 与计划和需求的偏差

1. **手雷（P1）没有实现**，在 `shop.json` 里设为 `enabled: false`。如果按源文档把手雷同时开放给两个角色，太阳花能同时持有的道具会有 7 种，超过 6 格快捷栏，违反 TR-CFG-05，配置校验会报错（已有测试覆盖）。可选的处理：手雷只给豌豆枪手、去掉一种种子，或者放宽这条规则。
2. **部分实现的 P1 需求**：FR-WPN-11（受击方向指示）没做；FR-WPN-12 只按材质区分了音效，没区分粒子；FR-MAP-08 的可打碎门窗没做，门只能按 F 开关；FR-AI-13 门口聚集没做；FR-SPD-06 环境预警只做了一部分。这些都记在 `docs/里程碑验收记录.md` 里。
3. **P2 不做**：护甲板、加速鞋在配置里设为 `enabled: false`。
4. **测试数量**：计划写的是约 30 条，实际 65 条，多出来的主要是边界和异常用例，另外新增了 `layout.test.ts`，验证地图连通性和建筑结构。

## 修订 1：僵尸模型与动作精细化（计划 Step 23～25）

需求方反馈原话：「僵尸的模型有点粗糙啊，能不能做的精美一点，还有僵尸的动作也要精美一点」

### 新增的文件

| 文件 | 内容 |
| --- | --- |
| `src/render/zombieGeometry.ts` | 16 种圆滑低多边形部件（车削体 / 球 / 胶囊），细节用顶点色烘焙在模型上 |
| `src/render/zombieRig.ts` | 分层骨架；每种部件一个实例化网格；`rollZombieLook(seed)` 决定个体差异 |
| `src/logic/zombiePose.ts` | 纯逻辑的程序化动画与姿态混合 |
| `tests/unit/zombiePose.test.ts` | 13 条测试 |

### 模型

PvZ 经典造型：
- 破西装：翻领、口袋、补丁、破洞、撕裂下摆
- 衬衫领口与条纹红领带
- 骨盆、四肢的肘部和膝盖补丁、上翘的鞋
- 头部：凹陷眼窝、眉骨、一大一小且方向不一致的眼珠、可开合的下颌、缺一颗的歪牙、稀疏头发、耳朵、缝合疤痕
- 带脏指甲的爪状手指

个体差异：身高 ±5%、体型、9 组配色、缺一只前臂（留断臂残端）、歪头、跛脚。

### 动作

- **姿态混合**：状态切换时用 0.2 s 平滑过渡（死亡 0.15 s），不再瞬间跳变。
- **IDLE**：重心晃动、头抽动、下颌咀嚼。
- **WANDER**：一条腿拖地的蹒跚步。
- **ALERT**：先转头、再转身、张嘴低吼。
- **CHASE**：前倾踉跄、双臂前伸，步频随移速变化。
- **ATTACK**：0.3 s 后仰蓄力（与游戏前摇时钟对齐），接前扑抓击，再收回。
- **BREAK**：双臂交替捶墙。
- **HIT_REACT**：按受击方向后仰、甩头、扭身，0.15 s 内恢复。
- **DEAD**：膝盖先软，再随机向前或向后倒下，手臂甩动，落地反弹一下后静止。
- **AMBUSH**：蹲伏，触发后起身。
- **特殊状态**：被藤蔓定身时挣扎；被减速时所有动作按比例放慢。
- **LOD**：> 60 m 用简化姿态，> 120 m 冻结。

### 配置与性能

- **配置**：全部视觉和动画数值都在 `game.json` 的 `zombieVisual` 一节。
- **校验**：
  - 混合时长在 0.15～0.25 s 之间
  - 身高差异不超过 ±5%
  - 死亡动作要在 `deathRemoveDelay` 内播完
  - 头部高度落在 `headHeightRange`（1.5～1.8 m）内，命中判定不受影响
- **Draw Call**：僵尸主渲染固定 16 个，与数量无关；阴影通道再加 11 个。
- **三角面**：每只约 3,400 面，40 只约 14 万，同屏上限 50 万。
- **玩法**：没有改变。`zombie.ts` 只加了动画要读取的受击记录字段。

### 验证

- `npx vitest run tests/unit`：16 个文件 / 78 条全部通过。
- `npm run build`：通过。
- 浏览器里的实际观感还没有确认。

## 修订 2：多种僵尸类型（计划 Step 26～29）

需求方反馈原话：「你参考植物大战僵尸游戏中的设定，再多加一些不同类型的僵尸，比如撑杆跳僵尸（速度更快，可以跳），铁桶僵尸（血条厚）等等」

这一修订推翻了源文档 NG-07「本期 1 种僵尸」。D-29 不变：启动时会校验每种僵尸的所有移速都低于玩家步行速度。

### 7 种僵尸

普通、路障、铁桶、撑杆跳、读报、铁门、橄榄球，数值见 `docs/数值表.md` 与 README「僵尸图鉴」（标【待调参】）。

### 规则（纯逻辑，有测试）

- `src/logic/armor.ts`：先扣护甲再结转本体；爆头倍率只算本体；路障 / 铁桶只护头，头盔护头和躯干，报纸挡正面 ±90°，铁门挡正面 ±60°；爆炸同时伤护甲和本体。
- `src/logic/zombieAbilities.ts`：撑杆跳只跳一次、约 1 s、跳跃中免疫藤蔓、落地降速到 1.4；读报暴怒 0.6 s 后提速到 3.2；橄榄球冲锋，距目标 3 m 内减到 2.0（这个 2.0 计划里没写，是新加的调参值）。
- 刷怪：按街区解锁类型，压力每升一级，重甲权重 ×(1 + 0.25 × 等级)；橄榄球同屏 ≤ 4、铁桶 ≤ 6。埋伏点和新手引导刷怪点只刷普通僵尸。
- 击杀奖励按类型 `sunDrop` 发放（`economy.killReward` 已移除）。

### 实体、模型、动作、音效

- 新状态 `VAULT`、`RAGE`；F4 显示「类型名 · 状态」。
- 8 种配件：路障（另有受损凹痕版）、铁桶、头盔、护肩、撑杆、报纸、铁门；护甲打掉后配件翻滚掉落，2 s 后缩小下沉消失，对象池上限 16。
- 动作：撑杆跳插杆弧线跃过、落地踉跄；读报边走边看，暴怒时跺脚怒吼，然后狂奔；铁门双手举门；橄榄球低头冲锋；打在护甲上头部晃动 ×1.8。
- 金属受击声、金属落地声、暴怒吼声，资源缺失时用 Web Audio 合成。
- 击杀飘字为「+N ☀ 类型名」。

### 性能

僵尸主渲染 Draw Call 固定 24 个（16 个身体部件 + 8 个配件），刚好用满预算；阴影通道 19 个。铁门纱网每扇约 5,000 个三角面。
